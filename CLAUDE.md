# Instruções para o Claude neste repositório

- Depois de implementar e validar qualquer alteração (commit feito, testes/typecheck/build ok),
  sempre abrir um Pull Request e fazer o merge automaticamente, sem perguntar antes. Só pare
  para perguntar se houver um conflito de merge que exija uma decisão (duas mudanças
  incompatíveis na mesma lógica).
